# dox.js - Doxing Nomor Telepon via Termux

**Author:** Mr X  
**Deskripsi:**  
Alat sederhana untuk doxing via nomor telepon. Jalankan langsung di Termux, tanpa embel-embel.

---

## Fitur

- `.phonelookup <nomor>` — Lacak info publik dari nomor telepon target (nama, lokasi, dll).

---

1. Clone Repositori

git clone https://github.com/mrrobotlo/doxing

cd doxing

2. Jalankan Tool

node dox.js
